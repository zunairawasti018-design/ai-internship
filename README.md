# AI Internship Projects

Weekly full-stack projects built during the AI internship.

## Week 3 — Real-Time RAG Application

An interactive full-stack RAG application where users upload documents and ask questions with live, token-by-token streaming responses.

The standalone Week 3 backend and frontend, setup guide, environment templates, and checks are in [`week-3/`](./week-3/README.md).

### Stack

- FastAPI, PostgreSQL, and Qdrant
- Background document ingestion with Sentence Transformers
- Groq chat completions streamed over Server-Sent Events
- Next.js frontend with live streaming and cancellable generation

See the [Week 3 README](./week-3/README.md) for setup instructions.
